# BrowserPicker

Маленькое приложение для строки меню macOS: назначается браузером по умолчанию и решает, куда отправить ссылку.

- Обычный клик: ссылка открывается по правилу сайта, а если правила нет, то в браузере по умолчанию (Safari).
- Клик с зажатыми ⌥⌘ (настраивается): появляется окно выбора браузера.
  - `1`–`9`: выбрать браузер, `↩`: подсвеченный, `Esc`: отмена.
  - `⇧` + цифра или галочка «Запомнить»: сохранить правило для сайта (`lkfl2.nalog.ru` сохранится как `nalog.ru`).
- Правила по сайтам: домен покрывает свои поддомены, поддерживаются маски `*` и `?`, при нескольких совпадениях побеждает самое длинное правило.
- Кнопка «Добавить госсайты» добавляет Диадок, Контур, ФНС, Госуслуги, ЕИС, СФР, Росреестр и Федресурс для выбранного ГОСТ-браузера.

## Установка

На любом маке одной командой:

```bash
curl -fsSL https://raw.githubusercontent.com/kzhebenev/browser-picker/main/get.sh | bash
```

Или скачать `BrowserPicker.dmg` из [релизов](https://github.com/kzhebenev/browser-picker/releases/latest) и перетащить в Applications.
Приложение подписано самоподписанным сертификатом, поэтому после скачивания браузером снимите карантин:
`xattr -dr com.apple.quarantine /Applications/BrowserPicker.app` (установка через `curl` этого не требует).

Дальше разрешите BrowserPicker в «Универсальном доступе» и включите в настройках «Запускать при входе».

## Синхронизация через iCloud

Настройки → «Синхронизировать через iCloud Drive». Файл настроек переезжает в
`iCloud Drive/BrowserPicker/config.json`, и все маки с включённой галочкой работают с ним:
правка правила на одном маке через несколько секунд действует на остальных.

- при включении правила этого мака добавляются к общим; если сайт уже есть в общих правилах, побеждает общее;
- браузер, которого на каком-то маке нет, там заменяется на Safari;
- локальная копия в `~/Library/Application Support/BrowserPicker/config.json` остаётся запасной, если iCloud выгрузил файл с диска.

## Обновления

Приложение проверяет релизы при запуске и раз в сутки, а также по пункту меню «Версия …: проверить обновления».
Все релизы подписаны одним сертификатом, поэтому «Универсальный доступ» после обновления сохраняется.

Выпуск новой версии (с мака, где лежит сертификат подписи):

```bash
echo 1.2 > VERSION && git commit -am "v1.2: ..." && ./release.sh "что нового"
```

Из исходников (нужны Xcode Command Line Tools): `./install.sh`.

## Как ловятся клики внутри Safari

Safari остаётся браузером по умолчанию. BrowserPicker перехватывает клик мышью глобально (event tap)
и узнаёт адрес ссылки под курсором через Accessibility: браузеры отдают элемент `AXLink` с атрибутом `AXURL`.
Для этого нужно разрешение: Системные настройки → Конфиденциальность и безопасность → Универсальный доступ → BrowserPicker.

- ⌥⌘ + клик по ссылке в любом приложении: клик не доходит до страницы, появляется окно выбора;
- обычный клик в браузере по сайту, для которого есть правило на другой браузер: ссылка сразу уходит туда
  (отключается в настройках);
- ссылки из других приложений (почта, Telegram) по желанию тоже можно пропускать через BrowserPicker,
  назначив его браузером по умолчанию (кнопка «Ловить и их»).

Приложение подписывается постоянным самоподписанным сертификатом (`setup-signing.sh` создаёт его один раз),
чтобы разрешение не сбрасывалось после пересборки.

Диагностика: `log stream --predicate 'process == "BrowserPicker"'` покажет, какую ссылку нашёл каждый перехваченный клик.

Запасные варианты: букмарклет
`javascript:location.href='browserpicker://pick?url='+encodeURIComponent(location.href)`
и пункт меню «Открыть ссылку из буфера…».

## Файлы

- настройки: `~/Library/Application Support/BrowserPicker/config.json`. Их можно править руками, изменения подхватываются при следующей ссылке;
- `browserpicker://pick?url=<ссылка>`: всегда показать окно выбора;
- `BrowserPicker.app/Contents/MacOS/BrowserPicker --selftest`: проверка сопоставления правил.
